# Motivase Site Blocker

モチベーション管理×サイトブロッカー Chrome 拡張。
気が散るサイトをネットワークレベル（declarativeNetRequest）でブロックし、代わりに
「やる気が出るテキスト・やることリスト・ポモドーロタイマー」を備えたブロック画面を表示します。
心理学の知見（実装意図・衝動への摩擦・自己モニタリング・ストリーク・コミットメントデバイス）を
UI に落とし込んだ、日本人ユーザー向けの集中支援ツールです。

## 主な機能

### ブロック
- **サイトブロック** — ドメイン全体（サブドメイン含む）/ ホスト完全一致 / パス前方一致の 3 種類のパターン。設定画面ではリアルタイムプレビュー（ブロックされる例・されない例・URL テスト）を見ながら登録できます
- **ワンクリックブロック** — ポップアップから範囲（ドメイン / ホスト / パス）を選んで即ブロック。キーボードショートカット（⌘/Ctrl+Shift+B）と右クリックメニューからも一発登録
- **カテゴリプリセット** — SNS / 動画 / まとめ・掲示板 / ネットニュース / ショッピングの日本向けプリセットを一括登録。グループ単位で ON/OFF でき、**まとめて解除**も 1 クリック
- **削除は確認ダイアログなし** — ルールの削除は即座に反映し、「元に戻す」で取り消せます（1 件ずつ確認を求められて手が止まることがありません）
- **追加した瞬間に効く** — ルールを追加・有効化すると、すでに開いているタブもブロック画面へ送り返します（スケジュール開始時も同様。一時許可中のドメインは対象外）
- **スケジュールブロック** — 「平日 9:00〜18:00 だけブロック」のような時間帯・曜日指定（日跨ぎ対応）。常時ブロックとルール単位で使い分け可能

### モチベーション管理
- **ブロック画面のカスタマイズ** — やる気が出るテキスト（自分の言葉を登録・ランダム表示）、やることリスト（未完了の先頭を「いま最優先」として提示）、ポモドーロタイマーを個別に ON/OFF・編集可能
- **やることリストの編集** — ドラッグで並べ替え（先頭が「いま最優先」になります）、項目をクリックして名前を変更。つまみにフォーカスして ↑↓ キーでも動かせます。削除は「元に戻す」で取り消せます
- **ポモドーロは時間をその場で選べる** — 15 / 25 / 45 / 60 分をブロック画面のワンタップで切り替え（選んだ長さは次回の既定値として保存）。作業中は未完了の先頭の項目を「いま取り組むこと」として表示
- **ブロックの理由（実装意図）** — ルールごとに「なぜブロックするか」を登録すると、ブロック画面に「あなたは『◯◯』のためにこのサイトをブロックしました」と表示
- **フォーカスモード** — 作業ポモドーロ中は一時許可を禁止し、スケジュール外のルールも強制ブロック（コミットメントデバイス）
- **統計とストリーク** — 今日/週間のブロック回数・一時許可時間・ポモドーロ完了数、連続達成日数🔥、GitHub 風ヒートマップ、よくブロックされたサイト。ツールバーバッジに今日のブロック回数を表示
- **祝福フィードバック** — ポモドーロ完了時にチャイム + 紙吹雪 + 進捗つき通知（正の強化）
- **週次振り返り** — 毎週月曜 9:00 に先週のサマリーを通知

### 一時許可（衝動ブレーキつき）
- 「10秒だけ開く」「1分だけ開く」など時間を決めて閲覧（選択肢は 5秒〜60分・最大6個で自由に変更可）。時間が切れるとタブは自動的にブロック画面へ戻ります
- **摩擦ゲート** — 開く前に「開く理由の入力」と「数秒の待機」を要求（one sec 式）。理由は履歴に残り、統計画面で振り返れます
- **日次予算** — ドメインごとに 1 日の許可合計時間へ上限。使い切ったらその日はもう開けません（早期再ブロックで残りは払い戻し）

### 自分を守る仕組み
- **厳格モード** — ルールの削除・無効化、一時許可・スケジュール設定の変更をロック。解除には決意の一文のタイプ入力が必要
- **バックアップ** — 設定・やること・統計を JSON でエクスポート / インポート（保存はこの端末の `chrome.storage.local` のみ。外部送信なし）

## 技術スタック

- [WXT](https://wxt.dev) + React 19 + TypeScript（Manifest V3）
- Tailwind CSS v4（テーマは **自動（OS 追従）/ ライト / ダーク** の 3 択。設定画面とブロック画面から切り替え可能）
- Vitest 120+ テスト（パターン解析・DNR ルール生成・スケジュール・統計・正規化・バックアップ検証）

## 開発

```bash
npm install        # 依存インストール（postinstall で wxt prepare が走る）
npm run dev        # 開発モード（Chrome が拡張入りで起動、HMR あり）
npm run test       # ユニットテスト
npm run compile    # 型チェック（tsc --noEmit）
npm run build      # 本番ビルド → .output/chrome-mv3/
npm run zip        # ストア提出用 zip
npm run icons      # public/icon/*.png を再生成
```

手動で読み込む場合: `npm run build` → `chrome://extensions` → 「デベロッパーモード」ON →
「パッケージ化されていない拡張機能を読み込む」→ `.output/chrome-mv3` を選択。

### E2E スモークテスト

実際の Chrome に拡張を読み込んで検証するスクリプト群があります。ブランド版 Chrome 137+ は
`--load-extension` が無効化されているため、[Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/)
が必要です（`npx @puppeteer/browsers install chrome@stable` で取得可能）。

```bash
npm run build
CHROME_BIN=<Chrome for Testing のパス> node scripts/e2e-smoke.mjs    # ブロック→摩擦ゲート→一時許可→再ブロック
CHROME_BIN=<同上> node scripts/e2e-extra.mjs                        # やること/ポモドーロ/バックアップ/popup
CHROME_BIN=<同上> node scripts/e2e-v2.mjs                           # 予算/フォーカスロック/スケジュール/プリセット/厳格モード/バッジ
CHROME_BIN=<同上> node scripts/e2e-ui.mjs                            # テーマ切替/一括解除/削除の取り消し/ポモドーロ時間
CHROME_BIN=<同上> node scripts/e2e-expiry.mjs                        # 30秒以上の一時許可が alarm 経由で失効するか
#   ALLOW_SEC=600 を付けると実時間 10 分で検証（既定は 40 秒）
CHROME_BIN=<同上> node scripts/e2e-restart.mjs                      # ブラウザ再起動を跨いだ永続性
CHROME_BIN=<同上> node scripts/e2e-screenshots.mjs <出力dir>        # 全画面のスクショ撮影
```

リリース前の確認手順は [docs/RELEASING.md](docs/RELEASING.md) にまとめてあります。

## 仕組みの要点

- ブロックは DNR の **dynamic rules**（`redirect`, `main_frame` のみ）。リダイレクト先は拡張内の
  `blocked.html#u=<元URL>`。リクエスト URL に `#` は含まれないため、フラグメント渡しで元 URL を
  クエリを壊さず復元できます
- ドメイン判定は `requestDomains`（Chrome の正規サブドメイン判定）を併用し、`youtube.com.evil.com`
  のようなホスト偽装を防止
- **「いま効いているルール」= enabled × スケジュール × フォーカスモード** を `lib/active.ts` で一元判定し、
  background が DNR に差分同期。スケジュール境界には alarm を張って自動で切り替え
- 一時許可は **session rules**（`allow`, priority 100）+ `chrome.alarms`（30 秒未満は SW 内 `setTimeout`
  併用）。`storage.session` と session ルールは同寿命（ブラウザ終了で両方消える）。フォーカスロックと
  日次予算のガードは background 側で強制されるため、UI をすり抜けても許可されません
- UI はどのサーフェスも storage に書くだけで、background が storage → DNR を差分同期します

## 制限事項（既知）

- `chrome://extensions` からの拡張自体の無効化は防げません（厳格モードの説明にも明記）
- ポモドーロのチャイムは拡張ページ（ブロック画面等）を開いているときのみ鳴ります（通知は常に出ます）
- 新しいタブページの置き換えは、manifest 固定でユーザーが後から無効化できないため採用していません

## プライバシー

利用者のデータを一切収集・送信しません。すべて端末内の `chrome.storage` にのみ保存されます。
詳細は [PRIVACY.md](PRIVACY.md) を参照してください。
