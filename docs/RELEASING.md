# リリース手順

## 1. 自動テストを通す

```bash
npm test && npm run compile && npm run lint && npm run build
```

ブロック機構・一時許可・background に触れた変更では E2E も回す（`README.md` の
「E2E スモークテスト」を参照）。

## 2. 手動で確認する

自動テストがカバーしていない領域です。ビルドした `.output/chrome-mv3` を
実際の Chrome プロファイルに読み込んで確認します。

- `chrome://extensions/shortcuts` で「このサイトをブロック」に項目が出ており、
  キーを割り当てるとブロックできる（既定では未割り当て。マニフェストで
  `suggested_key` を指定していないため）
- 右クリックメニュー「このサイトをブロック」が表示され、機能する
- ポモドーロ完了時に OS 通知が出る／チャイムが鳴る
- テーマ 3 択（自動 / ライト / ダーク）がブロック画面・設定画面・ポップアップすべてに効く
- ブラウザを完全に終了して再起動すると、一時許可が消えている
- ツールバーバッジに今日のブロック回数が表示される
- 週次振り返り通知（月曜 9:00 発火。確認するには端末時刻を進めるか alarm を手動で発火させる）

これらが自動化されていないのは、OS 通知・音声再生・キーボードショートカット・
ブラウザの完全再起動が、拡張機能を読み込んだヘッドレス環境では再現しにくいためです。

## 3. パッケージを作る

```bash
# package.json の version を上げてから
npm run zip   # → .output/motivase-site-blocker-<version>-chrome.zip
```

Chrome ウェブストアのデベロッパーダッシュボードから、この zip をアップロードします。

## 4. 掲載用スクリーンショットを撮る

```bash
CHROME_BIN=<Chrome for Testing> node scripts/e2e-screenshots.mjs <出力dir>
```

出力は 1280x800（ストアが受け付けるのは 1280x800 か 640x400 ちょうどのみ）。
ポップアップはキャンバス中央に配置して撮られます。
掲載情報にはプライバシーポリシー（[PRIVACY.md](../PRIVACY.md)）の URL と、
各権限の必要性の説明が求められます。
